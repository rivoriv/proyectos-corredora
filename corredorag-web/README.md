# Corredora G - Sitio Web

Sitio web oficial de Corredora G (corredorag.cl).

## Stack

- Python 3 + Flask
- HTML5 + CSS3
- Phusion Passenger

## Ejecucion

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py

Abrir: http://127.0.0.1:5000
