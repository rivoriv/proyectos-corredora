# Yapo Buscador - Propietarios Directos

Algoritmos de busqueda y filtrado de propiedades de duenos directos en Yapo.cl.

## Comunas cubiertas (8)

- yapo_buscador_santiago.py - Santiago
- yapo_buscador_providencia_nunoa.py - Providencia, Nunoa
- Yapo_buscador.py - Macul, San Miguel, Independencia, Recoleta, Las Condes

## Instalacion

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
