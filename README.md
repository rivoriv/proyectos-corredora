# Proyectos Corredora G

Repositorio con los proyectos de automatización y presencia web de **Corredora G** ([corredorag.cl](https://corredorag.cl)), corredora de propiedades especializada en arriendo en la Región Metropolitana de Santiago, Chile.

## Proyectos

### 🏠 Buscador de Propietarios en Yapo

Algoritmos de búsqueda y filtrado de propiedades publicadas por **dueños directos** en [Yapo.cl](https://www.yapo.cl). Descarta automáticamente avisos de corredoras e inmobiliarias.

**Comunas cubiertas:** Santiago, Providencia, Ñuñoa, Las Condes, Macul, San Miguel, Independencia y Recoleta.

📖 Ver documentación completa en [`yapo-buscador/README.md`](yapo-buscador/README.md)

### 🌐 Sitio Web Corredora G

Sitio web oficial con Flask, HTML5 y CSS3. Incluye landing page, información de servicios y formulario de contacto.

📖 Ver documentación completa en [`corredorag-web/README.md`](corredorag-web/README.md)

## Stack general

- **Python 3** — lenguaje principal
- **Playwright** — scraping de sitios web
- **Flask** — servidor web
- **Git** — control de versiones
